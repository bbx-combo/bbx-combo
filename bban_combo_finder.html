BBAN Combo Finder

Beyblade X tournament combinations across Australia. Only X1 and X2 tournaments are included. X3 is no longer included.
How to use this page

Choose Australia-wide or a specific state to view results from that region.

Use the search field or part filters to narrow the results. Select None for a component that is not used in a combination.

Rankings, points and summaries are recalculated automatically whenever a filter changes.

Use Reset filters to return to the complete Australia-wide results.

Data updated: 8 September 2026. Points are calculated from raw appearances: 1st place = 3 points, 2nd place = 2 points, 3rd place = 1 point, and every other notable appearance = 0.1 points. Source data provided by Mike.
